One original English sentence, at most 200 characters, phrased as an absurd
clause buried deep inside a terms-of-service agreement — deadpan legal
boilerplate that quietly turns absurd.

## The clause

> Section 14.2: by accepting these terms, you grant us a perpetual,
> royalty-free licence to your dreams, including the right to rerun them as
> advertisements while you sleep.

(171 characters, one line.)

## How it runs

`main.py` (Python 3, standard library only) writes the clause to
`/output/entry.txt`, asserting it is 1–200 characters, a single line, and not
only whitespace. The output file is written with plain `open()` and an
explicit `chmod 644` so the grader can read it.
